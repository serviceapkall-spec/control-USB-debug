# ATV Control (PKALL SERVICE)

แอปสำหรับกล่อง Android TV ที่**เปิด/ปิด USB Debugging**, ตั้งค่า DNS และสั่ง Reboot เข้าโหมดต่าง ๆ ผ่าน ADB ของตัวกล่องเอง (127.0.0.1:5555)
เมนูทั้งหมดอ่านจากไฟล์ XML ใน `app/src/main/assets/config/` ถ้าอยากเพิ่มหรือแก้เมนู ให้แก้ที่ไฟล์พวกนี้ ไม่ต้องแตะโค้ด

## วิธี build เป็น APK

1. เปิด Android Studio แล้วเลือก **File → Open** จากนั้นเลือกโฟลเดอร์ `ATVControl`
2. รอ Gradle sync ให้เสร็จ (ครั้งแรกต้องต่อเน็ต เพราะต้องโหลด Gradle 8.9 และ Android SDK 34)
3. เลือก **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
4. ไฟล์ที่ได้จะอยู่ที่ `app/build/outputs/apk/debug/app-debug.apk`

ถ้าอยากได้ไฟล์ release ให้เลือก Build Variant เป็น `release` ก่อน ตัวโปรเจกต์ตั้งให้เซ็นด้วย debug key ไว้แล้ว จึงติดตั้งลงกล่องได้ทันที

## ก่อนใช้งานบนกล่อง

แอปต้องใช้ ADB แบบเครือข่ายที่พอร์ต 5555 ซึ่งต้องเปิดก่อน 1 ครั้งต่อกล่อง:

- **กล่องที่มีเมนูเปิดให้:** ไปที่ Developer options แล้วเปิด USB debugging กับ ADB over network / Network debugging
- **กล่องที่ไม่มีเมนูนี้:** ต่อสาย USB หรือต่อผ่าน Wi-Fi จากคอม แล้วสั่ง `adb tcpip 5555` (ค่านี้จะหายเมื่อรีสตาร์ทกล่อง ยกเว้นรอมที่ตั้ง `persist.adb.tcp.port` ไว้)

ตอนกด CONNECT ครั้งแรก กล่องจะขึ้นหน้าต่าง "Allow USB debugging?" ให้ติ๊ก **Always allow** แล้วกด **Allow** หลังจากนั้นแอปจะเชื่อมต่อเองทุกครั้งที่เปิด

## เปิด/ปิด USB Debugging ทำงานยังไง

1. กด CONNECT ครั้งแรกจนขึ้น ADB CONNECTED แอปจะสั่ง `pm grant com.pkall.atvcontrol android.permission.WRITE_SECURE_SETTINGS` ให้เองอัตโนมัติ
2. ตั้งแต่นั้นแอปจะแก้ค่า `adb_enabled` ได้เองโดยตรง **ไม่ต้องผ่าน ADB** จึงเปิด USB Debugging กลับได้แม้ตอนที่ปิดอยู่
3. **ระบบกันพลาด:** ถ้าแอปยังไม่มีสิทธิ์นี้ จะไม่ยอมให้กดปิด เพราะถ้าปิดไปแล้วจะเปิดกลับเองไม่ได้ (โดยเฉพาะกล่องที่ซ่อนเมนู Developer options)
4. เมนู DNS ใช้สิทธิ์เดียวกัน จึงยังใช้ได้แม้ USB Debugging ปิดอยู่ ส่วนเมนู Reboot ต้องใช้ ADB เสมอ

ข้อควรรู้:
- ถ้าถอนการติดตั้งแอป แล้วลงใหม่ด้วยไฟล์ที่เซ็นด้วยกุญแจคนละตัว สิทธิ์จะหาย ต้องกด CONNECT ใหม่ (ซึ่งต้องเปิด USB Debugging ไว้ตอนนั้น)
- หลังเปิด USB Debugging กลับ พอร์ต 5555 จะกลับมาเองถ้ายังไม่ได้รีสตาร์ทกล่อง แต่ถ้ารีสตาร์ทแล้วอาจต้องสั่ง `adb tcpip 5555` ใหม่ ส่วนการเปิด/ปิดในแอปไม่ต้องใช้พอร์ตนี้

## ไฟล์ตั้งค่า

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| main.xml | รายการเมนูในหน้าแรก |
| welcome.xml | ข้อความในหน้าแรกและข้อความสถานะ |
| commands.xml | คำสั่ง shell ทั้งหมด (เมนูอ้างอิงด้วย `action`) |
| usb.xml / dns.xml / reboot.xml / support.xml | ปุ่มในแต่ละเมนู |

ปุ่มแต่ละปุ่มใส่ `warning="..."` ได้ ข้อความนี้จะแสดงในหน้าต่างยืนยันก่อนสั่งงาน
ปุ่มใน support.xml กำหนดได้ 2 แบบ: `type="text"` แสดงข้อความ หรือ `type="url"` เปิดลิงก์

**ข้อควรระวัง:** ใน commands.xml อย่าใส่คำสั่งที่แก้ไขระบบแบบย้อนกลับไม่ได้ เช่น `dd`, `flash`, `wipe`, `rm` หรือ `pm uninstall` แอปตัวที่ส่งให้นี้มีเฉพาะคำสั่งที่ไม่ทำให้เครื่องเสีย

## แก้เมนูผ่าน GitHub ได้โดยไม่ต้อง build ใหม่ (ไม่บังคับ)

1. อัปโหลดไฟล์ทั้งหมดจาก `assets/config` ขึ้น GitHub repo **ของคุณเอง**
2. แก้ `REMOTE_BASE_URL` ในไฟล์ `ConfigRepository.java` ให้เป็นลิงก์ raw ของโฟลเดอร์นั้น เช่น
   `https://raw.githubusercontent.com/<user>/<repo>/main/ATV-Control/`
3. build ใหม่ 1 ครั้ง

หลังจากนั้นถ้าแก้ไฟล์บน GitHub แอปจะโหลดเมนูชุดใหม่ทุกครั้งที่เปิด ถ้าไฟล์บน GitHub เสีย หรือกล่องไม่มีเน็ต แอปจะกลับไปใช้ชุดที่โหลดไว้ล่าสุดหรือชุดที่ติดมากับแอปแทน

## ข้อแตกต่างจากตัวต้นฉบับ

- **เพิ่มเมนู USB Debugging** (เปิด/ปิด พร้อมแสดงสถานะปัจจุบัน)
- **ตัดระบบ lock.xml ออก** ตัวต้นฉบับให้เจ้าของ repo สั่งล็อกแอปบนทุกกล่องจากระยะไกลได้ และเก็บรหัส admin/1234 ไว้แบบอ่านได้
- **เพิ่มคำสั่ง `REBOOT_UPDATE`** ที่ขาดไป (ในไฟล์ต้นฉบับ ปุ่ม BOOT Mode กดแล้วไม่มีผล)
- เพิ่มคำเตือนวิธีออกจาก Recovery / BOOT / Bootloader ในหน้าต่างยืนยัน และตั้งให้เคอร์เซอร์เริ่มที่ปุ่ม "ยกเลิก"
- หน้า Support แสดงข้อมูลร้าน PKALL SERVICE
